# Draw Music — instrument SoundFonts, pack 4 of 4

68 single-instrument SoundFonts, 35.1 MB. One preset per file, cut
from GeneralUser GS; bank and program are preserved, numbered from zero.

File names are `inst_b<bank>_p<program>.sf2`, zero padded to three digits.

## Why four repositories

jsDelivr refuses to serve a file it has not already cached when the package
it sits in is over 50 MB, and the full set is 140 MB. Split four ways each
pack is about 35 MB, so every file is servable. `sounds.json` lists what is
in this pack; the app's own manifest carries the same hashes.

Served from:

    https://cdn.jsdelivr.net/gh/trungtq2705/drawmusic-sf-4@v1/<file>.sf2
    https://raw.githubusercontent.com/trungtq2705/drawmusic-sf-4/v1/<file>.sf2
